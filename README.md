# 미션 3 - Mini NPU 패턴 판별 프로그램

## 1. 프로젝트 개요
이 프로그램은 **Mini NPU(Neural Processing Unit)** 의 동작 원리를 단순화하여 구현한 패턴 판별 프로그램입니다.

주어진 **패턴 행렬(pattern matrix)** 과 **필터 행렬(filter matrix)** 사이에  
**MAC(Multiply-Accumulate) 연산**을 수행하여 유사도를 계산하고,  
입력 패턴이 **Cross(+)** 인지 **X(x)** 인지 판별합니다.

또한 `data.json` 파일에 저장된 여러 크기의 필터와 패턴 데이터를 읽어  
자동으로 판별 정확도와 성능을 분석할 수 있습니다.

---

## 2. 주요 기능

### 모드 1: 사용자 입력 기반 3x3 패턴 판별
사용자가 직접 입력한

- 3x3 Cross 필터
- 3x3 X 필터
- 3x3 패턴

에 대해 MAC 연산을 수행하여 최종 판별 결과를 출력합니다.

### 모드 2: `data.json` 기반 자동 분석
`data.json`에 저장된

- 필터(`filters`)
- 패턴(`patterns`)

를 읽어 각 패턴에 대해 자동으로 다음을 수행합니다.

1. Cross 필터와 MAC 점수 계산
2. X 필터와 MAC 점수 계산
3. 더 높은 점수를 가진 라벨로 예측
4. 정답(`expected`)과 비교
5. 전체 정확도와 실패 사례 요약
6. 크기별 MAC 성능 측정

## 3. 사용 기술
- Python 3
- 표준 라이브러리만 사용
  - `json`
  - `time`

외부 라이브러리(예: NumPy, Pandas)는 사용하지 않았습니다.
